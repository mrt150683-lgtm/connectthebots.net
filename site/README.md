The browser and recording scripts need Playwright. Set `PLAYWRIGHT_MODULE` to a Playwright `index.js` if it is not globally resolvable (CI uses the pinned copy in `workbench/ui`). For account checks, set `PYTHON` if the interpreter with server dependencies is not the default. No real Google account or email service is contacted by these checks.

## Deploying

Static target: Ubuntu 22.04 or 24.04. The hosted application supports Ubuntu 24.04 and Python 3.12. DNS for the apex and www must resolve to the intended server. Review the [hosted deployment and approval requirements](../docs/HOSTED_SERVER.md) before using these examples.

```bash
site/deploy/deploy.sh ubuntu@YOUR_SERVER_IP --dry-run                      # shows what would happen
site/deploy/deploy.sh ubuntu@YOUR_SERVER_IP --email you@example.com        # upload + full setup with HTTPS
# Windows (built-in OpenSSH and tar, no WSL needed):
powershell -ExecutionPolicy Bypass -File site\deploy\deploy.ps1 -Server root@YOUR_SERVER_IP -Email you@example.com
```

`deploy.sh` copies the site over SSH and runs `server-setup.sh` with sudo. The setup installs nginx, Let's Encrypt (Certbot), GoAccess and the `ufw` firewall (SSH, HTTP, HTTPS only), turns on automatic security updates, applies a strict content security policy and security headers, maps `/signin` and `/app`, and refuses to request a certificate until DNS points at the server and no stray AAAA record points elsewhere. Rerun it to publish changes. Options: `--skip-tls` before DNS is ready, `--no-firewall` when the provider manages the firewall.

## Visit statistics

Cookie-free and first-party. nginx writes shortened IPs and fixed path categories; GoAccess builds the private `/stats/` report every ten minutes. Shortening does not guarantee anonymisation. Queries, raw unknown paths, user agents and referrers are not retained, so browser/device/referrer detail is unavailable. Dynamic route logs are suppressed. Set a stats password interactively with `sudo htpasswd /etc/nginx/connectthebots.htpasswd stats`; setup never prints its generated password. Logs rotate after 30 days. There is no tracking script.
