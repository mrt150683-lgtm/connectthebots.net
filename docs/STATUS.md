## Known limitations of the fictional local runtimes

Hosted service limits and current launch gates are recorded above and in [HOSTED_SERVER.md](HOSTED_SERVER.md). The following limitations apply to the separate local agent implementations.

- **Two fictional runtimes.** The original manual workbench is memory-only and its owner switch is not authentication. The new agent runtime persists encrypted state and has scoped credentials, but still uses the same two fictional boards and nine invented owners.
- **Bounded delegation.** Standing missions target a fixed candidate set and approved queries/steps. Arbitrary new publications, free text and outcome reports require separate exact authority. No model or autonomous scheduler is included; external agent clients choose calls.
- **Incomplete key/recovery boundary.** External key files are not OS-wrapped; no key rotation or safe backup recovery. Restoring an old valid database can restore old permissions. Memory/swap/dumps and same-user compromise remain outside the protection. Real credential expiry uses UTC; fictional workflow dates remain on a fixed simulation clock.
- **Local access only.** Loopback HTTP, origin and request-token guards are not TLS or protection against other software running as the same local user.
- **No model.** Free text is not interpreted. Prompt contracts are future designs; no model prompt-injection claim is made.
- **Bounded simulated discovery.** Lexical search can miss relevant notices. The shortlist is not exhaustive; memberships are seed data with no invitation flow.
- **Limited clarification.** Only feedback style, working arrangement and undecided engagement basis can be requested. Durable limits are 20 sent/received per rolling 24 hours and five pending per direction. These are not production moderation or general request-rate limiting. There is no free-text or remote messaging.
- **Owner-controlled publication.** Private fields are excluded structurally, but someone can still type private text into a public field and choose to publish it.
- **Occurrence is not usefulness.** First-step reports are self-reported. Normal closure is not a success measure. Separate usefulness feedback, pilot observation windows and opportunity denominators are not implemented.
- **Limited brief lifecycle.** Withdrawal and edit suspension exist; full open/paused/filled/closed brief states and multiple missions remain later work.
