# Code of conduct

AgentMatch is about people choosing to work together. The same standard applies to the people building it.

## Expected behavior

- Be respectful and assume good faith. Disagree with ideas, not people.
- Give and accept constructive feedback.
- Respect privacy. Never share someone's personal information without their explicit permission.
- Respect a "no". Declining to engage, review or continue a discussion is a boundary, not a problem to argue with.

## Unacceptable behavior

- Harassment, intimidation, or discriminatory language or imagery.
- Sexualized comments or unwelcome attention.
- Publishing others' private information, including conversations or contact details.
- Sustained disruption of discussion.

## Enforcement

Maintainers may edit or remove contributions, or restrict participation, for behavior that breaks this code. Report concerns privately to the maintainers through the repository owner's GitHub profile. Reports are handled confidentially.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
